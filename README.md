# Useful components

This repository is used to compile all useful components that I made for my React projects

## Installation

1.  **Clone :**

```bash
git clone https://github.com/Azarta2Zygoto/useful-components.git
cd useful-components
```

2.  **Download all dependences :**
    You need to have <https://nodejs.org/en/download/>[npm] on your computer or another package manager (yarn, pnp, bun).

```bash
npm install
```

3.  **Development :**
    To run the website on a browser in development mode :

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

To build the project at a production mode :

```bash
npm run build
```

The webpage is host at http://localhost:3000.
